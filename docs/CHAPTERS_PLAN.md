## 总体结构

**核心叙事轴**：回溯权限随救人增长 → 每章回溯到更早的时间点 → 水位一层层退去、
小镇一步步"活"过来 → 离真相越来越近。玩家在时间线上向左走，灾难在时间线上向右逼近。

```
第四章(数周前·真相) ← 第三章(数天前·连锁) ← 第二章(数小时前·暴雨夜) ← 第一章(洪水后·现状)
```

| 章 | 名称 | 时间点 | 水位/环境 | 核心情绪 |
|---|---|---|---|---|
| 序章 | 水中醒来 | 洪水后 1h | 全淹没（已实现的开场） | 绝境 |
| 第一章 | 水下一小时 | 洪水后 0~1h | 全淹没 | 求生与取舍（已完成） |
| 第二章 | 洪水之夜 | 洪水前 6h | 暴雨夜，水位渐涨 | 争分夺秒的疏散 |
| 第三章 | 灾变的链条 | 洪水前 3 天 | 阴天，河道异常 | 追查与防御 |
| 第四章 | 逆转的天灾 | 洪水前 3 周 | 平静小镇（最后的日常） | 阻止与抉择 |
| 尾声 | 真相 | —— | —— | 回扣"系统"身份 |

## 分章设计

### 第二章「洪水之夜」（暴雨+内涝，对应文档"暴雨/洪水"行）
- **场景**：暴雨夜的小镇街道。雨幕粒子、能见度降低；街道上有水流推力（顺流快、逆流慢）。
- **核心机制反转**：倒计时不再是"水位上涨"，而是**"距离洪水发生"**——玩家在洪水来临前
  劝说/护送居民前往高地避难点。倒计时归零 = 洪水瞬间灌入（演出），按当轮疏散人数结算，
  未疏散者进入第一章的受困名单（章节间数据打通：第二章多救一人，第一章少救一人压力）。
- **新玩法元素**（源自文档 I 列）：① 水流推力场；② 民居敲门劝说（对话选择：老人不肯走→
  搬出子女照片/收音机预警等，对应文档"预警征兆"知识）；③ 落水电线区（单脚跳通过）。
- **知识卡组**（暴雨/洪水行 D/E/F/G）：城市内涝高处避水、涉水防井盖、落水电线、驾车弃车、山洪横向逃生、溺水心肺复苏、人链转移、直升机信号（已有 8 张可复用+新增预警类 4~6 张）。
- **真相线索**：疏散中听到水库"例行泄洪公告"，但时间与水文数据对不上 → 章末系统提示"权限不足以继续回溯，需更多碎片"。

### 第三章「灾变的链条」（连锁灾害，对应文档"山洪/溃坝/触电"要素）
- **场景**：洪水前 3 天。上游峡谷+水库大坝。山体有滑坡迹象，河水浑浊上涨。
- **新玩法元素**（文档 I 列的钓鱼/建造/物理）：
  ① **绳索救援**（"钓鱼类机制"）：激流中抛绳救落水者——蓄力抛物线+收线 QTE；
  ② **沙袋堤坝**（建造类轻量版）：在缺口处堆沙袋堵水，为疏散争取时间；
  ③ **触电险区**：被淹的配电箱区域，接近需断电操作（小型交互解谜）。
- **取舍升级**：三个区域的救援目标+限时，明确"救不完"——文档 J 列"救不了所有的人需要取舍"的完全体。
- **知识卡组**：山洪征兆（乌云+闷雷）、绳索激流救援、沙袋堆堤、触电断电施救、断肢/外伤急救（文档 G 列）。
- **真相推进**：在大坝监控室发现——泄洪闸的调度指令来自一个**不存在的操作员账号**，且时间戳被人改过 → 人为实锤，指向第四章。

### 第四章「逆转的天灾」（终章·阻止灾变）
- **场景**：洪水前 3 周的完整小镇——阳光、干燥、所有第一章"废墟"都是完好原貌（同一张地图的
  另一种状态，复用关卡数据的反向验证）。
- **核心循环**：**时间循环关**——一天的时间窗口内，调查"那个账号"背后的操作者、阻止大坝引爆装置布设、
  疏散关键人物。一天结束强制回卷重来（有限次数=回溯权限），保留已完成的子目标（类《死亡循环》的轻量版）。
- **最终取舍**：结局前系统给出选择——用全部回溯权限换"完全阻止"，或保留权限承担风险。
  按累计获救/失落人数 + 关键选择 → **三结局**：完美逆转 / 遗憾拯救 / 真相大白但代价惨重。
- **真相揭晓**（见决策点 A）。

比赛精神的延续）。
